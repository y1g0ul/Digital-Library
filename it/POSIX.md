POSIX (Portable Operating System Interface) - набор стандартов, описывающих общие интерфейсы и поведение Unix-подобных операционных систем. Главная задача POSIX - обеспечить **переносимость программ** между разными ОС.

POSIX стандартизирует, например:
- работу с файлами и директориями;
- процессы и сигналы;
- права доступа;
- стандартные системные интерфейсы;
- поведение shell;
- базовые консольные утилиты.

[[Linux]], BSD и macOS во многом поддерживают POSIX, поэтому программы, использующие стандартные POSIX-интерфейсы, обычно проще переносить между ними. При этом POSIX - не операционная система, а стандарт.

Упрощённо:
`POSIX = общий набор правил для Unix-подобных систем`
