Система на базе [[Linux]] состоит не только из самого ядра. Обычно в неё входят несколько основных компонентов:
- **Начальный загрузчик (GRUB)** - это программа, которая отвечает за загрузку операционной системы. Она выполняется на этапе начальной загрузки и предоставляет выбор операционных систем или конфигураций для загрузки ядра.
- **[[kernel|Ядро Linux]]** - управляет процессами, памятью, устройствами, файловыми системами и другими ресурсами компьютера.
- **GNU-утилиты и другие системные инструменты** - команды и программы для работы с системой: `ls`, `cp`, `grep`, `bash` и другие.
- **init system** - запускает систему после старта ядра и управляет службами. Чаще всего используется [[systemd]].
- **Системные службы (Демоны)** - фоновые процессы: [[networks/SSH|SSH]]-сервер, журналирование, сеть и другие.
- **shell** - оболочка для взаимодействия с системой через командную строку, например [[Bash]].
- **Системные библиотеки** - предоставляют программам готовые функции для взаимодействия с системой. Например, `glibc`.
- **Пользовательские приложения** - браузеры, редакторы, серверы, Docker и другие программы.

Упрощённо:
```text
Пользовательские программы
        ↓
Системные библиотеки и утилиты
        ↓
Системные службы / shell
        ↓
Linux kernel
        ↓
Оборудование
```

[[Linux]] - это в первую очередь **ядро**, а полноценная операционная система получается уже из ядра вместе с остальными компонентами.
