Preboot Execution Environment - механизм загрузки компьютера по сети без использования локального диска или заранее установленной операционной системы.

Обычно PXE работает так:
```text
Компьютер включается
        ↓
Получает IP и параметры загрузки по DHCP
        ↓
Скачивает загрузчик по сети
        ↓
Загружает ядро / установщик ОС
```

Для PXE обычно используются:
- [[DHCP]] - выдаёт IP-адрес и сообщает, откуда брать загрузчик;
- TFTP или HTTP - используются для передачи загрузочных файлов;
- загрузчик - например GRUB или iPXE.

Процесс загрузки сервера
1. Начинается с выполнения PXЕ-кода сетевой карты.
2. Запрашивает сетевые настройки по DHCP.
3. Получает ответ с TFTP опциями (адрес tftp сервера + имя файла).
4. PXE-загрузчик (первичный загрузчик) ограничен 32 Кб, поэтому загрузка идет в 2 стадии.
5. PXE-загрузчик запускает следующий исполняемый файл.
6. Загрузка в LiveCD образ.

PXE часто используют для:
- массовой установки ОС;
- автоматического развёртывания серверов;
- загрузки без локального диска;
- восстановления и диагностики систем.

PXE поддерживается как в BIOS, так и в UEFI.
