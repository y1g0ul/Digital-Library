Команда в [[Linux]] для просмотра открытых файлов и объектов ввода-вывода, которые используются процессами.

В Linux почти всё представлено как файл, поэтому `lsof` показывает не только обычные файлы, но и сокеты, устройства, pipes и сетевые соединения.

```bash
lsof [ключи] [объект]
```

| Ключ       | Что делает                               |
| ---------- | ---------------------------------------- |
| `-p`       | показать объекты конкретного PID         |
| `-u`       | показать объекты пользователя            |
| `-i`       | показать сетевые соединения              |
| `-i :PORT` | показать, кто использует порт            |
| `+D`       | показать открытые файлы внутри каталога  |
| `-t`       | вывести только PID                       |
| `-n`       | не преобразовывать IP в DNS-имена        |
| `-P`       | не преобразовывать номера портов в имена |

Основные поля:

| Поле      | Что показывает                |
| --------- | ----------------------------- |
| `COMMAND` | имя процесса                  |
| `PID`     | PID процесса                  |
| `USER`    | пользователь                  |
| `FD`      | файловый дескриптор           |
| `TYPE`    | тип объекта                   |
| `NAME`    | файл, сокет или другой объект |

Примеры:

```bash
lsof
# показать все открытые объекты

lsof -p 1234
# показать открытые файлы процесса

lsof -u root
# показать объекты пользователя root

lsof /var/log/app.log
# узнать, какой процесс держит файл открытым

lsof +D /var/log
# показать открытые файлы внутри каталога

lsof -i
# показать сетевые соединения

lsof -i :80
# узнать, какой процесс использует порт 80

lsof -iTCP:22
# показать TCP-соединения на порту 22

lsof -iTCP -sTCP:LISTEN -nP
# показать процессы, слушающие TCP-порты

lsof -t -i :8080
# вывести только PID процесса на порту 8080
```

Полезный случай:

```bash
lsof +L1
# показать удалённые файлы, которые процессы всё ещё держат открытыми
```

Это помогает искать ситуацию, когда файл удалён, но место на диске не освободилось.
