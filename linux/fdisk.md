Утилита в [[Linux]] для просмотра и изменения **таблицы разделов диска**. Современный `fdisk` умеет работать как с **MBR**, так и с **GPT**.

```bash
sudo fdisk /dev/sdX
```

Например:
```bash
sudo fdisk /dev/sdb
```

После запуска открывается интерактивный режим.

Основные команды:

|Команда|Что делает|
|---|---|
|`p`|показать текущую таблицу разделов|
|`n`|создать новый раздел|
|`d`|удалить раздел|
|`t`|изменить тип раздела|
|`l`|показать список доступных типов|
|`w`|записать изменения на диск и выйти|
|`q`|выйти без сохранения|
|`m`|показать справку|

Посмотреть таблицу разделов без входа в интерактивный режим:
```bash
sudo fdisk -l
```

Для конкретного диска:
```bash
sudo fdisk -l /dev/sda
```

Важно: пока не выполнена команда `w`, изменения обычно не записываются на диск.

`fdisk` изменяет именно **разделы**, но не создаёт внутри них файловую систему. После создания раздела обычно отдельно используется [[mkfs]], например:
```bash
sudo mkfs.ext4 /dev/sdb1
```

Для просмотра дисков перед работой удобно использовать `lsblk`:
```bash
lsblk
```

> Ошибка при выборе диска или раздела может привести к потере данных, поэтому перед использованием `fdisk` всегда стоит перепроверять имя устройства.
