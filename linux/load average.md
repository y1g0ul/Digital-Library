Параметр, определяющий среднюю нагрузку на систему за период времени (1 мин, 5 минут, 15 минут). **Среднее количество задач, готовых к выполнению на CPU (`R`) или находящихся в непрерываемом ожидании (`D`). Для оценки CPU-нагрузки значение сравнивают с количеством логических CPU.**  Также влияние на расчета LA оказывает: 
1. Технология Hyper-Threading, которая делит одно физическое ядро на 2 логических, 
2. Технология Turbo Bust, которая позволяет разгонять тактовую частоту процессора и работать на частоте выше заявленной, т.е. выше номинальной частоты (время на обработку одной задачи уменьшается).

Показатель можно посмотреть командами:
``` bash
uptime
top
w
cat /proc/loadavg
```

| Значение | Что означает |
|----------|--------------|
| Первое | средняя нагрузка за 1 минуту |
| Второе | средняя нагрузка за 5 минут |
| Третье | средняя нагрузка за 15 минут |

Интерпретация:

| Load Average | Для 1 CPU | Для 4 CPU |
|--------------|-----------|-----------|
| `0` | процессор простаивает | процессоры простаивают |
| `1` | процессор полностью загружен | загружено 1 из 4 ядер |
| `2` | одно задание ожидает CPU | загружено 2 из 4 ядер |
| `4` | очередь из процессов | все 4 ядра полностью заняты |

Количество логических процессоров:

``` bash
nproc
lscpu
```

> Для оценки нагрузки Load Average следует сравнивать с количеством **логических CPU (потоков)**. Например, при 12 логических процессорах `load average = 12` означает полную загрузку системы, а `24` — процессы начинают ждать освобождения CPU.

Примеры:

``` bash
uptime              # показать Load Average
top                 # показать нагрузку в реальном времени
cat /proc/loadavg   # посмотреть Load Average из procfs
nproc               # количество логических процессоров
lscpu               # подробная информация о CPU
```
