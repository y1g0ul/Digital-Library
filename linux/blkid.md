Команда в [[Linux]] для просмотра информации о блочных устройствах и файловых системах.

```bash
blkid [ключи] [устройство]
```

Обычно показывает:
```text
/dev/sda1: UUID="..." TYPE="ext4" PARTUUID="..."
```

### UUID

UUID файловой системы или [[swap]].
- уникальный идентификатор
- создаётся вместе с файловой системой
- обычно не меняется при перезагрузке
- используется в:
    - `/etc/`[[fstab]]
    - [[systemd]]
    - [[mount]]
    - `swapon`

Пример:
```text
UUID="4c8d-1234"
```

Если переформатировать раздел, UUID обычно изменится.

### TYPE

Тип содержимого раздела:
```text
ext4
xfs
vfat
ntfs
swap
```

Например:
```text
TYPE="ext4"
```

### LABEL

Человекочитаемая метка файловой системы.

Например:
```text
LABEL="DATA"
```

Её можно использовать вместо UUID, если удобно обращаться к разделу по имени.

### PARTUUID

Уникальный идентификатор **самого раздела в таблице разделов**, а не файловой системы внутри него.

```text
PARTUUID="57ce0f9d-..."
```
- создаётся при создании раздела
- относится к partition table
- не зависит от файловой системы внутри раздела
- может использоваться при загрузке системы, в GRUB и [[systemd]]

Главное отличие:
```text
Раздел
└── PARTUUID
    └── файловая система
        └── UUID
```

То есть:
```text
PARTUUID → идентификатор раздела
UUID     → идентификатор файловой системы
```

### PARTLABEL

Имя раздела, записанное в таблице разделов.

Например:
```text
PARTLABEL="Linux filesystem"
```

### Примеры

```bash
sudo blkid
# показать информацию обо всех найденных устройствах

sudo blkid /dev/sda1
# информация о конкретном разделе

sudo blkid -s UUID /dev/sda1
# показать UUID

sudo blkid -s TYPE /dev/sda1
# показать тип файловой системы

blkid -L DATA
# найти устройство по LABEL

blkid -U 4c8d-1234
# найти устройство по UUID
```

Полезно помнить:

```text
lsblk
→ структура дисков и разделов

blkid
→ UUID, TYPE, LABEL, PARTUUID

findmnt
→ что и куда смонтировано
```
