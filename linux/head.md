Команда в [[Linux]] для вывода первых строк файла или входного потока.
```bash
head [ключи] <файл>
```

По умолчанию выводит первые **10 строк**.

|Ключ|Что делает|
|---|---|
|`-n`|указать количество строк|
|`-c`|указать количество байт|
|`-q`|не выводить имя файла|
|`-v`|всегда выводить имя файла|

Примеры:
```bash
head file.txt
# показать первые 10 строк

head -n 5 file.txt
# показать первые 5 строк

head -5 file.txt
# сокращённая запись предыдущей команды

head -c 100 file.txt
# показать первые 100 байт

head file1.txt file2.txt
# показать начало нескольких файлов

head -q file1.txt file2.txt
# несколько файлов без заголовков с именами

ps aux | head
# показать первые строки вывода команды

cat file.txt | head -n 20
# показать первые 20 строк потока
```

Часто используется вместе с другими командами:
```bash
ps aux --sort=-%mem | head
# показать процессы с наибольшим использованием памяти

du -ah /var | sort -rh | head -n 10
# показать 10 самых больших файлов/каталогов
```
