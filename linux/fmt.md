Команда в [[Linux]] для форматирования обычного текста: разбивает слишком длинные строки и объединяет короткие строки в абзацы заданной ширины.

```bash
fmt [ключи] [файл]
```

По умолчанию старается делать строки шириной примерно **75 символов**.

|Ключ|Что делает|
|---|---|
|`-w <n>`|задать максимальную ширину строки|
|`-s`|только разбивать длинные строки, не объединяя короткие|
|`-u`|привести пробелы между словами к одному|
|`-p <prefix>`|форматировать только строки с указанным префиксом|

Примеры:

```bash
fmt file.txt
# отформатировать текст из файла

fmt -w 60 file.txt
# ограничить строки шириной 60 символов

cat file.txt | fmt -w 80
# форматирование через pipe

fmt -s file.txt
# только разбивать слишком длинные строки

fmt -u file.txt
# нормализовать пробелы
```

Пример:

До:
```text
Это очень длинная строка текста которая продолжается дальше и дальше и плохо читается в терминале.
```

После:
```text
Это очень длинная строка текста которая продолжается дальше и
дальше и плохо читается в терминале.
```

`fmt` работает именно с обычным текстом и абзацами. Это не утилита для форматирования кода или таблиц.

Главная идея:
```text
текст
↓
fmt
↓
аккуратные строки заданной ширины
```

Полезно вместе с:
```text
fold
→ просто переносит строки по ширине

fmt
→ старается переносить по словам и сохранять структуру абзацев
```
