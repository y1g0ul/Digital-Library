Команда в [[Linux]] для вывода текста или значений переменных в терминал. Часто используется в [[Bash]]-скриптах и вместе с перенаправлением вывода.

```
echo [ключи] [текст]
```

|Ключ|Что делает|
|---|---|
|`-n`|не добавлять перевод строки в конце|
|`-e`|интерпретировать специальные последовательности (`\n`, `\t` и др.)|
|`-E`|не интерпретировать специальные последовательности|

### Специальные последовательности

Работают с `echo -e` в Bash.

|Последовательность|Что делает|
|---|---|
|`\n`|новая строка|
|`\t`|табуляция|
|`\\`|обратный слеш|
|`\r`|возврат курсора в начало строки|

### Примеры
```
echo "Hello, Linux!"
# вывести текст

echo "$HOME"
# показать домашний каталог

echo "$PATH"
# показать значение переменной PATH

echo $?
# показать код завершения предыдущей команды

echo -n "Loading..."
# вывести текст без перевода строки

echo -e "Hello\nWorld"
# вывести текст в две строки

echo -e "Name:\tNikita"
# использовать табуляцию
```

### Перенаправление вывода

```
echo "Hello" > file.txt
# записать текст в файл, перезаписав его содержимое

echo "World" >> file.txt
# добавить текст в конец файла

echo "APP_ENV=production" > .env
# создать файл с переменной окружения для приложения
```

### Одинарные и двойные кавычки

```
echo "$HOME"
# Bash подставит значение переменной

echo '$HOME'
# выведет буквально $HOME
```

**Важно:** `echo` обычно является встроенной командой оболочки (shell builtin), хотя существует и отдельная программа `/usr/bin/echo`.

Для сложного форматирования и предсказуемой обработки специальных символов лучше использовать `printf`.

```
printf 'Hello\nWorld\n'
# форматированный вывод с явным переводом строк
```
