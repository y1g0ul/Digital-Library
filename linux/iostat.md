Команда которая показывает статистику CPU и устройств ввода-вывода (диски).

``` bash
iostat [ключи] [интервал]
```

| Ключ | Что делает                                                                                |
| ---- | ----------------------------------------------------------------------------------------- |
| `-c` | только статистика CPU                                                                     |
| `-d` | только статистика дисков                                                                  |
| `-x` | расширенная статистика устройств                                                          |
| `-m` | вывод в MB вместо KB                                                                      |
| `-p` | показать разделы дисков                                                                   |
| `-y` | убрать первый отчёт после запуска                                                         |
| `-z` | скрытия из отчета тех устройств, у которых не было никакой активности за отчетный период. |
  Основные поля CPU:

| Поле      | Что показывает                                           |
| --------- | -------------------------------------------------------- |
| `%user`   | время работы пользовательских процессов                  |
| `%nice`   | время работы процессов с изменённым приоритетом [[nice]] |
| `%system` | работа ядра [[Linux]]                                    |
| `%iowait` | ожидание завершения операций ввода-вывода                |
| `%steal`  | время, забранное гипервизором (виртуальные машины)       |
| `%idle`   | простой CPU                                              |

Поля устройств:

| Поле        | Что показывает                                           |
| ----------- | -------------------------------------------------------- |
| `tps`       | количество запросов ввода-вывода к устройству в секунду. |
| `kB_read/s` | скорость чтения данных                                   |
| `kB_wrtn/s` | скорость записи данных                                   |
| `kB_dscd/s` | скорость удаления данных (discard/TRIM)                  |
| `kB_read`   | общее количество прочитанных данных                      |
| `kB_wrtn`   | общее количество записанных данных                       |

Расширенные поля устройств (`iostat -x`):

| Поле | Что показывает |
|---|---|
| `r/s` | количество операций чтения в секунду |
| `rkB/s` | скорость чтения в KB/s |
| `rrqm/s` | количество объединённых запросов чтения в секунду |
| `%rrqm` | процент объединённых запросов чтения |
| `r_await` | среднее время ожидания операции чтения |
| `rareq-sz` | средний размер запроса чтения |
| `w/s` | количество операций записи в секунду |
| `wkB/s` | скорость записи в KB/s |
| `wrqm/s` | количество объединённых запросов записи в секунду |
| `%wrqm` | процент объединённых запросов записи |
| `w_await` | среднее время ожидания операции записи |
| `wareq-sz` | средний размер запроса записи |
| `d/s` | количество операций discard/TRIM в секунду |
| `dkB/s` | скорость discard/TRIM в KB/s |
| `drqm/s` | количество объединённых discard-запросов |
| `%drqm` | процент объединённых discard-запросов |
| `d_await` | среднее время ожидания discard/TRIM |
| `dareq-sz` | средний размер discard-запроса |
| `f/s` | количество flush-операций в секунду |
| `f_await` | среднее время ожидания flush |
| `aqu-sz` | средняя длина очереди запросов к устройству |
| `%util` | процент времени, когда устройство было занято обработкой запросов |

Примеры:
``` bash
iostat                  # показать статистику CPU и дисков
iostat 2                # обновлять каждые 2 секунды
iostat -x               # расширенная статистика дисков
iostat -xm 1            # расширенная статистика в MB каждую секунду
iostat -c               # показать только CPU
iostat -d               # показать только диски
iostat -p               # показать разделы дисков
```

Для диагностики чаще всего смотрят на: 
```bash
r_await / w_await # задержка чтения и записи 
aqu-sz # очередь запросов 
%util # насколько постоянно устройство занято r/s, 
w/s # количество операций rkB/s, 
wkB/s # объём чтения и записи
```
