Команда в [[Linux]] для отображения структуры файлов и каталогов в виде дерева.

```bash
tree [ключи] [путь]
```

|Ключ|Что делает|
|---|---|
|`-a`|показать скрытые файлы|
|`-d`|показывать только каталоги|
|`-L <n>`|ограничить глубину дерева|
|`-f`|показывать полный путь|
|`-h`|показывать размеры в удобном формате|
|`-s`|показывать размер файлов|
|`-p`|показывать права доступа|
|`-u`|показывать владельца|
|`-g`|показывать группу|
|`-I <pattern>`|исключить файлы/каталоги по шаблону|
|`-P <pattern>`|показывать только подходящие по шаблону|

Примеры:
```bash
tree
# показать дерево текущего каталога

tree /etc
# показать дерево /etc

tree -L 2
# показать только 2 уровня вложенности

tree -a
# показать скрытые файлы

tree -d
# показать только каталоги

tree -h
# показать размеры файлов

tree -I ".git|node_modules"
# исключить .git и node_modules

tree -P "*.conf"
# показать только .conf файлы
```

Полезно для быстрого просмотра структуры проекта или файловой системы:
```text
project/
├── app/
│   ├── main.py
│   └── config.py
├── tests/
└── README.md
```
