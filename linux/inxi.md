Команда в [[Linux]] для быстрого получения сводной информации о системе и железе.

Показывает CPU, GPU, RAM, диски, сеть, ядро, дистрибутив, драйверы и другие параметры.

```
inxi [ключи]
```

### Основные ключи

|Ключ|Что показывает|
|---|---|
|`-S`|система: дистрибутив, ядро, desktop|
|`-C`|процессор|
|`-G`|видеокарта и графический драйвер|
|`-M`|материнская плата / модель устройства|
|`-m`|оперативная память|
|`-D`|диски|
|`-N`|сетевые адаптеры|
|`-A`|аудио|
|`-B`|батарея|
|`-s`|датчики температуры|
|`-I`|общая системная информация|
|`-F`|полный системный отчёт|
|`-x`|добавить больше подробностей|
|`-xx`|ещё больше подробностей|
|`-xxx`|максимально подробный вывод|

### Примеры

```
inxi -S
# информация о системе

inxi -C
# информация о CPU

inxi -G
# GPU и графический драйвер

inxi -m
# информация об оперативной памяти

inxi -D
# диски

inxi -N
# сетевые адаптеры

inxi -s
# температуры и датчики

inxi -B
# аккумулятор

inxi -F
# полный отчёт
```

Можно комбинировать ключи:

```
inxi -CGm
# CPU + GPU + RAM

inxi -SN
# система + сеть

inxi -Fxx
# полный и более подробный отчёт
```

### Для отправки отчёта

Полезный вариант:

```
inxi -Fxxxz
```

`-z` скрывает часть чувствительной информации, например некоторые MAC/IP-данные.

Это удобно при отправке системной информации на форум или в чат для диагностики.

### Чем отличается от других команд

```
lscpu
→ подробно про CPU

lsblk
→ диски и разделы

lspci
→ PCI-устройства

sensors
→ датчики

dmidecode
→ SMBIOS/DMI

inxi
→ собирает всё это в одну удобную сводку
```

Главная идея:

```
Linux system
   ↓
inxi
   ↓
краткая сводка о железе,
драйверах и системе
```
