Команда в [[Linux]] для просмотра смонтированных файловых систем и точек монтирования. Более удобная альтернатива просмотру `/proc/mounts` или выводу `mount`.

```bash
findmnt [ключи] [устройство или точка монтирования]
```

|Ключ|Что делает|
|---|---|
|`-t`|показать только указанный тип файловой системы|
|`-S`|искать по устройству или источнику|
|`-T`|найти файловую систему по пути|
|`-o`|выбрать выводимые столбцы|
|`-r`|вывод без дерева|
|`-n`|без заголовков|
|`-J`|вывести результат в JSON|

Основные поля:

|Поле|Что показывает|
|---|---|
|`TARGET`|точка монтирования|
|`SOURCE`|устройство или источник|
|`FSTYPE`|тип файловой системы|
|`OPTIONS`|параметры монтирования|

Примеры:
```bash
findmnt
# показать дерево всех смонтированных файловых систем

findmnt /
# показать файловую систему корня /

findmnt /home
# показать файловую систему /home

findmnt -T /var/log/syslog
# определить, на какой файловой системе находится файл

findmnt -S /dev/sda1
# найти, куда смонтировано устройство

findmnt -t ext4
# показать только ext4

findmnt -t proc,sysfs,tmpfs
# показать выбранные виртуальные файловые системы

findmnt -o TARGET,SOURCE,FSTYPE,OPTIONS
# вывести только нужные поля

findmnt -r
# вывести список без древовидной структуры

findmnt -J
# вывести данные в JSON
```

Особенно полезная команда:
```bash
findmnt -T <путь>
```

Позволяет быстро определить, **какая файловая система и устройство отвечают за конкретный файл или каталог**.
