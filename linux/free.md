Утилита в [[Linux]] для отображения использования оперативной памяти (RAM) и [[swap]].  Показывает общее количество памяти, занятую, свободную и доступную.

`free [опции]`

|Опция|Описание|
|---|---|
|`-h`|Человекочитаемый формат (K, M, G)|
|`-m`|Вывод в мегабайтах|
|`-g`|Вывод в гигабайтах|
|`-k`|Вывод в килобайтах|
|`-s N`|Обновление каждые N секунд|
|`-c N`|Количество обновлений|
|`-t`|Показать итоговую строку|
Что показывает free

|Поле|Значение|
|---|---|
|`total`|Общий объём памяти|
|`used`|Используемая память|
|`free`|Полностью свободная память|
|`shared`|Используемая несколькими процессами|
|`buff/cache`|Буферы и файловый кэш|
|`available`|Доступная для новых процессов память|
``` bash
free                 # стандартный вывод
free -h              # человекочитаемый формат
free -m              # вывод в мегабайтах
free -s 2            # обновление каждые 2 секунды
free -s 1 -c 5       # 5 обновлений с интервалом 1 секунда
free -t              # показать итог
```

### Кэширование оперативной памяти

Linux использует свободную оперативную память для кэширования данных, чтобы ускорить работу системы.

**Page Cache** (кэш страниц) и **Buffer Cache** (буферный кэш) - это механизмы операционной системы для ускорения работы с диском. Первый кэширует содержимое файлов в виде страниц памяти для быстрого чтения и записи, а второй хранит сырые дисковые блоки и метаданные файловой системы.

- Page Cache (Кэш страниц):
    - Сохраняет реальные данные файлов, к которым обращались программы.
    - Ускоряет операции чтения и записи на уровне файлов.
    - Занимает бо́льшую часть памяти в строке `buff/cache` системных утилит. 

- Buffer Cache (Буферный кэш):
    - Сохраняет сырые блоки диска (блочные устройства) и служебную информацию (метаданные).
    - Согласовывает передачу данных между структурой файловой системы и диском.
    - Имеет меньший размер по сравнению с кэшем страниц.
