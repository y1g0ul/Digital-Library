Команда в [[Linux]] для просмотра текущей и исторической статистики производительности системы. В отличие от [[top]], [[mpstat]] и [[iostat]], `sar` умеет читать данные, которые `sysstat` собирал ранее.

```bash
sar [ключи] [интервал] [количество]
```

|Ключ|Что показывает|
|---|---|
|`-u`|загрузку CPU|
|`-r`|использование памяти|
|`-S`|использование swap|
|`-b`|общую статистику I/O|
|`-d`|статистику дисков|
|`-n DEV`|статистику сетевых интерфейсов|
|`-n TCP`|статистику TCP|
|`-q`|Load Average и очередь процессов|
|`-W`|swap in/out|
|`-f`|читать данные из указанного файла|
|`-s`|начать вывод с указанного времени|
|`-e`|закончить вывод в указанное время|

Примеры:
```bash
sar
# показать статистику CPU за текущий день

sar 2 5
# показать CPU каждые 2 секунды 5 раз

sar -u 2
# загрузка CPU каждые 2 секунды

sar -r
# статистика оперативной памяти

sar -S
# использование swap

sar -b
# общая статистика ввода-вывода

sar -d
# статистика дисков

sar -n DEV
# статистика сетевых интерфейсов

sar -n TCP
# статистика TCP

sar -q
# Load Average и очередь процессов

sar -W
# операции swap in / swap out
```

Исторические данные обычно находятся в:
```text
/var/log/sysstat/
```

Файлы имеют вид:
```text
sa24
```

где `24` — день месяца.

Посмотреть статистику за другой день:
```bash
sar -f /var/log/sysstat/sa23
# статистика за 23 число
```

Посмотреть определённый период:
```bash
sar -s 10:00:00 -e 12:00:00
# статистика между 10:00 и 12:00
```

Главное отличие:
```text
top / mpstat / iostat
→ в основном текущая нагрузка

sar
→ текущая + историческая статистика
```

`sar` особенно полезен, когда проблема уже произошла и нужно понять, что происходило с CPU, RAM, диском или сетью в тот момент.
