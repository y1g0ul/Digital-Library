## Основные элементы

**Специальные символы**

|Символ|Значение|
|---|---|
|`.`|Любой символ, кроме новой строки|
|`^`|Начало строки|
|`$`|Конец строки|
|`\`|Экранирование специального символа|
|`[abc]`|Любой символ из перечисленных|
|`[a-z]`|Любая строчная буква латинского алфавита|
|`[0-9]`|Любая цифра от 0 до 9|
|`[^0-9]`|Любой символ, кроме цифры|

Примеры:

```
^error       # Строка начинается с error
error$       # Строка заканчивается на error
^error$      # Строка содержит только error
[0-9]        # Любая цифра
\.           # Буквальная точка
```

### Квантификаторы

Определяют количество повторений предыдущего элемента.

|Символ|Значение|
|---|---|
|`*`|0 или больше повторений|
|`+`|1 или больше|
|`?`|0 или 1|
|`{n}`|Ровно n повторений|
|`{n,}`|Не менее n повторений|
|`{n,m}`|От n до m повторений|

Примеры:

```
a*          # Ноль или больше a
a+          # Одна или больше a
a?          # Ноль или одна a
[0-9]{3}    # Три цифры подряд
[0-9]{2,4}  # От двух до четырёх цифр подряд
```

### Группировка и выбор

|Символ|Значение|
|---|---|
|`()`|Группировка выражений|
|`\|`|Логическое ИЛИ|

Примеры:

```
(cat|dog)    # cat или dog
(ab)+        # ab, abab, ababab...
```

## Виды регулярных выражений в Linux

Важный момент: не все утилиты [[Linux]] используют одинаковый синтаксис регулярных выражений.

| Тип  | Где используется           | Особенности                                    |
| ---- | -------------------------- | ---------------------------------------------- |
| BRE  | `grep`, `sed` по умолчанию | Базовый синтаксис                              |
| ERE  | `grep -E`, `sed -E`, `awk` | Расширенный синтаксис                          |
| PCRE | `grep -P`                  | Дополнительные возможности, совместимые с Perl |

В BRE символы `+`, `?`, `{}`, `()` и `|` обычно требуют экранирования для специального значения.

Например:
```
grep 'cat\|dog' file.txt
```

В ERE это выглядит проще:

```
grep -E 'cat|dog' file.txt
```

**Для большинства повседневных задач удобно использовать `grep -E`.**

### PCRE

`grep -P` - использование Perl-Compatible Regular Expressions.

Дополнительные возможности:

|Выражение|Значение|
|---|---|
|`\d`|Цифра|
|`\w`|Буква, цифра или `_`|
|`\s`|Пробельный символ|
|`\b`|Граница слова|
|`(?=...)`|Положительная проверка текста впереди (lookahead)|
|`(?<=...)`|Положительная проверка текста позади (lookbehind)|

Примеры:

```
# Строки, содержащие три цифры подряд
grep -P '\d{3}' file.txt

# Найти cat, только если после него идёт dog
grep -oP 'cat(?=dog)' file.txt

# Найти dog, только если перед ним стоит cat
grep -oP '(?<=cat)dog' file.txt
```

Здесь `-o` выводит только совпавшую часть строки, а не всю строку целиком.

## Практические примеры

### grep - поиск текста

```
# Строки, начинающиеся с ERROR
grep '^ERROR' app.log

# Строки, заканчивающиеся на .conf
grep '\.conf$' files.txt

# Строки с тремя цифрами подряд
grep -E '[0-9]{3}' file.txt

# Строки, содержащие ERROR или WARNING
grep -E 'ERROR|WARNING' app.log

# Строки, состоящие только из цифр
grep -E '^[0-9]+$' file.txt
```

### sed - замена текста

Общий синтаксис:
```
sed 's/шаблон/замена/флаги' file.txt
```

Примеры:
```
# Заменить первое cat на dog в каждой строке
sed 's/cat/dog/' file.txt

# Заменить все cat на dog
sed 's/cat/dog/g' file.txt

# Удалить все цифры
sed 's/[0-9]//g' file.txt

# Удалить пустые строки
sed '/^$/d' file.txt

# Заменить ERROR и WARNING на ALERT
sed -E 's/ERROR|WARNING/ALERT/g' file.txt
```

По умолчанию `sed` выводит изменённый текст в терминал, не изменяя исходный файл. Для редактирования файла используется `-i`:
```
sed -i 's/cat/dog/g' file.txt
```

---

> [!tip] Что важно запомнить  
> Для повседневной работы с логами и текстом достаточно знать `^`, `$`, `.`, `[]`, `*`, `+`, `?`, `{}`, `|` и `()`.
> 
> Основные инструменты:
> 
> - `grep -E` - поиск с расширенными регулярными выражениями.
> - `grep -P` - поиск с дополнительными возможностями PCRE.
> - `sed -E` - обработка и замена текста.
> 
> **Регулярное выражение описывает шаблон, а команда определяет, что делать с найденным совпадением.**
