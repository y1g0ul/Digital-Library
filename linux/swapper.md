`PID 0` - специальная задача ядра [[Linux]], которая появляется ещё до запуска обычных пользовательских процессов.

Это не обычный процесс вроде `bash`, `nginx` или `systemd`. Он существует внутри ядра и связан с работой планировщика и состоянием простоя CPU.

Упрощённо:
```text
Загрузка ядра
    ↓
PID 0
    ↓
ядро запускает PID 1
    ↓
systemd / init
    ↓
остальные процессы
```

### Зачем нужен PID 0

Когда процессорному ядру нечего выполнять, Linux не оставляет его буквально «без процесса».

Вместо этого выполняется специальная **idle-задача**:
```text
CPU занят процессом
      ↓
процесс закончил работу
      ↓
готовых задач нет
      ↓
CPU выполняет idle-задачу
```

То есть idle-задача означает:
> «Сейчас этому CPU нечего делать, можно ждать следующую работу и экономить энергию».

В многопроцессорной системе у каждого логического CPU есть собственная idle-задача, связанная с механизмом `swapper/idle`.

### Почему его не видно в ps

`PID 0` не является обычным пользовательским процессом, поэтому:
```bash
ps aux
```

обычно его не показывает. Он существует на уровне ядра и имеет особый статус.

### Связь с PID 1

Во время загрузки из контекста PID 0 ядро запускает первый обычный пользовательский процесс:
```text
PID 0
 ↓
PID 1
 ↓
systemd
 ↓
services
 ↓
обычные процессы
```
