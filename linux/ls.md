Команда в [[Linux]] для просмотра файлов и каталогов.

```bash
ls [ключи] [путь]
```

|Ключ|Что делает|
|---|---|
|`-l`|подробный вывод|
|`-a`|показать скрытые файлы|
|`-h`|размеры в удобном формате|
|`-t`|сортировать по времени изменения|
|`-r`|обратная сортировка|
|`-d`|показать сам каталог, а не его содержимое|
|`-i`|показать номер [[inode]]|
|`-R`|рекурсивно показать содержимое каталогов|
|`-S`|сортировать по размеру|
|`-1`|по одному объекту на строку|
|`--color=auto`|цветной вывод по типу объекта|

Скрытым считается файл или каталог, имя которого начинается с точки:
```text
.bashrc
.ssh
.config
```

### Подробный вывод

```bash
ls -l
```

Пример:

```text
-rw-r--r-- 1 user user 1234 Sep 3 12:00 file.txt
```

Первый символ показывает тип объекта:

|Символ|Тип|
|---|---|
|`-`|обычный файл|
|`d`|каталог|
|`l`|символическая ссылка|
|`b`|блочное устройство|
|`c`|символьное устройство|
|`s`|сокет|
|`p`|named pipe / FIFO|

Дальше идут:

```text
-rw-r--r--
 │
 ├── права владельца
 ├── права группы
 └── права остальных
```

### Часто используемые комбинации

```bash
ls -la
# подробный вывод со скрытыми файлами

ls -lh
# подробный вывод с удобными размерами

ls -ltr
# сортировка по времени, новые файлы внизу

ls -lt
# новые файлы сверху

ls -lS
# сортировка по размеру

ls -ld /etc
# показать информацию о самом каталоге /etc

ls -li
# показать inode

ls -R
# рекурсивно показать всё дерево каталогов
```

### Родственные утилиты

|Команда|Что показывает|
|---|---|
|`lsblk`|диски, разделы и блочные устройства|
|`lspci`|устройства PCI / PCIe|
|`lsusb`|USB-устройства|
|`lscpu`|информацию о CPU|
|`lsmem`|информацию об оперативной памяти|
|`lsipc`|IPC-объекты|
|`lslocks`|активные блокировки файлов|
|`lsmod`|загруженные модули ядра|

Для модулей ядра также используются:
```bash
modinfo <module>
# информация о модуле

modprobe <module>
# загрузить модуль с зависимостями

modprobe -r <module>
# выгрузить модуль

insmod module.ko
# загрузить модуль напрямую

rmmod <module>
# выгрузить модуль напрямую
```

`modprobe` обычно предпочтительнее `insmod` и `rmmod`, потому что умеет работать с зависимостями модулей.
