Команда в [[Linux]] для периодического выполнения другой команды и обновления её вывода на экране.

```bash
watch [ключи] <команда>
```

По умолчанию команда выполняется каждые **2 секунды**.

|Ключ|Что делает|
|---|---|
|`-n <сек>`|задать интервал обновления|
|`-d`|подсвечивать изменения|
|`-t`|убрать заголовок `watch`|
|`-g`|завершиться, когда вывод изменится|
|`-e`|показать ошибку команды и остановиться|

Примеры:

```bash
watch sensors
# обновлять показания датчиков каждые 2 секунды

watch -n 1 sensors
# обновлять каждую секунду

watch -d -n 1 sensors
# обновлять каждую секунду и подсвечивать изменения

watch -n 1 free -h
# наблюдать за памятью

watch -n 1 'ps aux --sort=-%cpu | head'
# наблюдать за самыми нагруженными процессами

watch -n 1 'ss -tulpn'
# следить за сокетами

watch -n 1 'cat /proc/mdstat'
# следить за состоянием RAID
```

Главная идея:
```text
watch
→ запускает команду
→ ждёт заданный интервал
→ запускает её снова
→ обновляет экран
```

Остановить:
```text
Ctrl + C
```

Особенно полезно вместе с командами мониторинга:
```text
sensors
free
df
ss
ps
cat /proc/mdstat
```
