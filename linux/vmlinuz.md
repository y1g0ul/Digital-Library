Это файл с **сжатым ядром Linux**, который загрузчик (например, [[GRUB]]) загружает в память при старте системы.

Название исторически расшифровывается примерно так: `vm` — virtual memory, `linux` — Linux, а `z` означает, что ядро сжато.

Обычно файл находится в `/boot`, например:
```
/boot/vmlinuz-6.8.0-xx-generic
```

При загрузке происходит примерно следующее: BIOS/UEFI → GRUB → загружается `vmlinuz` → ядро распаковывается и запускается → подключается `initramfs` → запускается основная Linux-система.

Важно: `vmlinuz` - это **не вся операционная система**, а именно исполняемый образ ядра Linux. Рядом с ним часто лежат `initrd`/`initramfs`, `System.map` и файл конфигурации ядра.

Ошибка  при установке [[Linux]]: файл /casper/vmlinuz не найден - нужно запустить rufus от имени администратора.
