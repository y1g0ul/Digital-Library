Команда в [[Linux]] для просмотра загрузки CPU по отдельным логическим процессорам.

```bash
mpstat [ключи] [интервал]
```

|Ключ|Что делает|
|---|---|
|`-P ALL`|показать статистику по всем CPU|
|`-P <номер>`|показать конкретный CPU|
|`-u`|показать загрузку CPU|
|`-I ALL`|показать статистику прерываний|
|`-A`|вывести всю доступную статистику|

Основные поля:

| Поле      | Что показывает                                            |
| --------- | --------------------------------------------------------- |
| `CPU`     | номер логического процессора, `all` — среднее по всем CPU |
| `%usr`    | время выполнения пользовательских процессов               |
| `%nice`   | пользовательские процессы с изменённым `nice`             |
| `%sys`    | время работы ядра                                         |
| `%iowait` | время ожидания операций ввода-вывода                      |
| `%irq`    | обработка аппаратных прерываний                           |
| `%soft`   | обработка программных прерываний                          |
| `%steal`  | время CPU, забранное гипервизором у виртуальной машины    |
| `%guest`  | время выполнения виртуального CPU гостевой системы        |
| `%gnice`  | время гостевой системы с изменённым `nice`                |
| `%idle`   | время простоя CPU                                         |
Примеры:

```bash
mpstat
# общая статистика CPU

mpstat 2
# обновлять статистику каждые 2 секунды

mpstat -P ALL
# показать каждый логический CPU отдельно

mpstat -P ALL 2
# загрузка всех CPU каждые 2 секунды

mpstat -P 0 2
# наблюдать только CPU 0

mpstat -I ALL
# показать статистику прерываний

mpstat -A 2
# показать всю статистику каждые 2 секунды
```

`mpstat` особенно полезен, когда общая загрузка CPU выглядит нормальной, но нужно проверить, не перегружено ли одно конкретное ядро.

```text
top / uptime
→ общая картина

mpstat -P ALL
→ нагрузка каждого CPU отдельно
```
