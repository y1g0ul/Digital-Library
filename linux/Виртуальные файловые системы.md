Виртуальные файловые системы в [[Linux]] - файловые системы, которые не хранят данные на обычном диске. Они предоставляют через файлы информацию о ядре, [[процесс]]ах, устройствах и состоянии системы.

Основные:

| Файловая система | Точка монтирования       | Что содержит                                  |
| ---------------- | ------------------------ | --------------------------------------------- |
| `procfs`         | `/proc`                  | процессы и параметры ядра ([[proc]])          |
| `sysfs`          | `/sys`                   | устройства, драйверы и объекты ядра ([[sys]]) |
| `tmpfs`          | `/run`, `/dev/shm` и др. | временные данные в RAM                        |
| `devtmpfs`       | `/dev`                   | файлы устройств ([[dev]])                     |
| `cgroupfs`       | `/sys/fs/cgroup`         | управление ресурсами процессов ([[cgroups]])  |

### /proc

`procfs` предоставляет информацию о процессах и ядре.
```bash
ls /proc
# посмотреть содержимое procfs

cat /proc/cpuinfo
# информация о CPU

cat /proc/meminfo
# информация о памяти

cat /proc/loadavg
# Load Average

ls /proc/1234
# информация о процессе с PID 1234
```

Каждый процесс имеет каталог:
```text
/proc/<PID>/
```

Например:
```text
/proc/1234/status
/proc/1234/cmdline
/proc/1234/fd/
```

### /sys

`sysfs` показывает устройства и объекты ядра и позволяет читать или изменять некоторые их параметры.
```bash
ls /sys/class/net
# сетевые интерфейсы

ls /sys/block
# блочные устройства

ls /sys/class
# классы устройств
```

### /dev

Содержит специальные файлы, через которые программы работают с устройствами.
```bash
ls /dev/sda
# диск

ls /dev/tty
# терминальные устройства

ls /dev/null
# специальное устройство, отбрасывающее данные

ls /dev/urandom
# источник случайных данных
```

### tmpfs

Временная файловая система, данные которой обычно хранятся в оперативной памяти и исчезают после перезагрузки.
```bash
mount | grep tmpfs
# посмотреть tmpfs

df -h /dev/shm
# посмотреть размер tmpfs
```

Часто используется для:
```text
/run
/dev/shm
```

### cgroupfs

Интерфейс [[cgroups]], через который ядро ограничивает и учитывает ресурсы процессов.
```bash
ls /sys/fs/cgroup
# посмотреть cgroups
```

Используется, например, [[Docker]] и [[systemd]] для контроля CPU, RAM и других ресурсов.

Главная идея:
```text
обычная файловая система
файлы → данные на диске

виртуальная файловая система
файлы → данные ядра / процессов / устройств
```

Посмотреть смонтированные виртуальные файловые системы:
```bash
mount
# показать все файловые системы

findmnt
# показать дерево монтирования

findmnt -t proc,sysfs,tmpfs,devtmpfs,cgroup2
# показать основные виртуальные файловые системы
```
