Команда в [[Linux]] для просмотра динамических библиотек, которые нужны исполняемому файлу или другой shared library.

```bash
ldd [ключи] <файл>
```

|Ключ|Что делает|
|---|---|
|`-v`|подробный вывод|
|`-u`|показать неиспользуемые зависимости|
|`-d`|проверить отсутствующие объекты и relocations|
|`-r`|проверить relocations и отсутствующие функции|

Пример вывода:
```text
libc.so.6 => /lib/x86_64-linux-gnu/libc.so.6
libm.so.6 => /lib/x86_64-linux-gnu/libm.so.6
```

Слева - библиотека, которая нужна программе.  
Справа - файл библиотеки, найденный в системе.

Если библиотека отсутствует:
```text
libexample.so => not found
```

Примеры:
```bash
ldd /usr/bin/ls
# показать библиотеки, необходимые ls

ldd /usr/bin/ssh
# посмотреть зависимости ssh

ldd ./my_program
# проверить библиотеки своей программы

ldd -v ./my_program
# подробная информация

ldd ./my_program | grep "not found"
# найти отсутствующие библиотеки
```

Главная идея:
```text
Программа
   ↓
динамический linker
   ↓
libc.so
libssl.so
libpthread.so
...
```

`ldd` помогает понять, **какие shared libraries нужны программе и где Linux их нашёл**.
