Основные каталоги файловой системы [[Linux]] и их назначение.
```text
/
├── bin
├── boot
├── dev
├── etc
├── home
├── lib
├── media
├── mnt
├── opt
├── proc
├── root
├── run
├── sbin
├── srv
├── sys
├── tmp
├── usr
└── var
```

| Директория | Что находится                                                         |
| ---------- | --------------------------------------------------------------------- |
| `/`        | корень всей файловой системы                                          |
| `/bin`     | основные пользовательские команды (`ls`, `cp`, `cat`)                 |
| `/sbin`    | системные административные команды                                    |
| `/boot`    | ядро Linux, initramfs, файлы загрузчика                               |
| `/dev`     | файлы устройств (`sda`, `tty`, `null`)                                |
| `/etc`     | системные конфигурационные файлы                                      |
| `/home`    | домашние каталоги обычных пользователей                               |
| `/root`    | домашний каталог пользователя `root`                                  |
| `/lib`     | системные библиотеки и модули ядра                                    |
| `/media`   | автоматическое монтирование флешек, дисков и других носителей         |
| `/mnt`     | временное ручное монтирование файловых систем                         |
| `/opt`     | дополнительное стороннее ПО                                           |
| `/proc`    | виртуальная файловая система с информацией о процессах и ядре         |
| `/run`     | временные данные работающей системы: [[PID]], сокеты, состояния служб |
| `/srv`     | данные, предоставляемые серверными службами                           |
| `/sys`     | виртуальная файловая система с информацией об устройствах и ядре      |
| `/tmp`     | временные файлы                                                       |
| `/usr`     | большая часть программ, библиотек и общих данных системы              |
| `/var`     | изменяемые данные: логи, кэши, очереди, базы и т.д.                   |

## Важные подкаталоги

### /etc/

Конфигурация системы и программ.
```text
/etc/ssh/
/etc/nginx/
/etc/systemd/
/etc/fstab
/etc/hosts
```

### /var/

Данные, которые постоянно изменяются.
```text
/var/log/        # логи
/var/lib/        # данные служб и приложений
/var/cache/      # кэш
/var/spool/      # очереди заданий
```

### /usr/

Основная часть установленного ПО.
```text
/usr/bin/        # пользовательские программы
/usr/sbin/       # административные программы
/usr/lib/        # библиотеки
/usr/share/      # общие данные программ
/usr/local/      # программы, установленные вручную администратором
```

### /proc/

Информация о процессах и ядре. ([[proc]])
```text
/proc/<PID>/     # информация о процессе
/proc/cpuinfo    # CPU
/proc/meminfo    # память
/proc/loadavg    # Load Average
```

### /sys/

Информация об устройствах, драйверах и объектах ядра. ([[sys]])
```text
/sys/class/net/  # сетевые интерфейсы
/sys/block/      # блочные устройства
```

Главная идея:
```text
/etc   → конфигурация
/home  → файлы пользователей
/var   → изменяемые данные
/usr   → программы и библиотеки
/dev   → устройства
/proc  → процессы и ядро
/sys   → устройства и ядро
/boot  → загрузка системы
```
