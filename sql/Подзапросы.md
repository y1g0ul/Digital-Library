Подзапрос - это [SQL](SQL)-запрос, вложенный внутрь другого запроса. Результат внутреннего запроса используется внешним запросом.

Базовый синтаксис:
```
SELECT *
FROM table
WHERE column = (
    SELECT ...
);
```

Например, найти пользователей, чей возраст больше среднего:
```
SELECT *
FROM users
WHERE age > (
    SELECT AVG(age)
    FROM users
);
```

Сначала выполняется внутренний запрос:
```
SELECT AVG(age)
FROM users;
```

Допустим, результат - `25`.

Тогда внешний запрос фактически становится:
```
SELECT *
FROM users
WHERE age > 25;
```

## Подзапрос с IN

Подзапрос может возвращать несколько значений.

Например, найти пользователей, которые сделали хотя бы один заказ:
```
SELECT *
FROM users
WHERE id IN (
    SELECT user_id
    FROM orders
);
```

Внутренний запрос возвращает список `user_id`, а внешний выбирает пользователей, чьи `id` входят в этот список.

## Подзапрос с EXISTS

`EXISTS` проверяет, возвращает ли подзапрос хотя бы одну строку.

```
SELECT *
FROM users u
WHERE EXISTS (
    SELECT 1
    FROM orders o
    WHERE o.user_id = u.id
);
```

Вернёт пользователей, у которых есть хотя бы один заказ.

`SELECT 1` используется потому, что `EXISTS` проверяет только наличие строк, а не их содержимое.

## Подзапрос в FROM

Результат подзапроса можно использовать как временную таблицу внутри другого запроса.

```
SELECT *
FROM (
    SELECT city, AVG(price) AS avg_price
    FROM sales
    GROUP BY city
) AS city_stats
WHERE avg_price > 150;
```

Здесь:
1. Внутренний запрос считает среднюю стоимость продажи по каждому городу.
2. Внешний запрос выбирает города, где средняя стоимость больше `150`.

`city_stats` - псевдоним результата подзапроса.

## Подзапрос в SELECT

Можно добавить результат подзапроса отдельным столбцом:
```
SELECT
    seller,
    price,
    (SELECT AVG(price) FROM sales) AS avg_price
FROM sales;
```

Результат:

|seller|price|avg_price|
|---|---|---|
|Alex|100|160|
|Bob|200|160|
|Kate|150|160|
|John|300|160|
|Max|50|160|

Средняя стоимость всех продаж добавляется к каждой строке.

Аналогичный результат можно получить с помощью [[Оконные функции]]:
```
SELECT
    seller,
    price,
    AVG(price) OVER () AS avg_price
FROM sales;
```

## Главное

Подзапрос может возвращать:

|Результат|Пример использования|
|---|---|
|Одно значение|`WHERE age > (SELECT AVG(age) ...)`|
|Несколько значений|`WHERE id IN (SELECT user_id ...)`|
|Набор строк и столбцов|`FROM (SELECT ...) AS t`|

**Важно:** если подзапрос используется с оператором '=', `>` или `<` в качестве одного значения, он должен возвращать не более одной строки. Если строк окажется несколько, PostgreSQL выдаст ошибку.

Подзапросы позволяют использовать результат одного SQL-запроса внутри другого.
