Оконные функции в [SQL](SQL) выполняют вычисления над набором строк, **не объединяя их в одну строку**, в отличие от [[Агрегатные функции]] с [[GROUP BY]].

Позволяют считать суммы, средние значения, нумеровать строки и сравнивать их между собой.

Базовый синтаксис:
```
SELECT
    column,
    function() OVER (...)
FROM table;
```

`OVER()` указывает, что функция является оконной, и определяет набор строк, с которыми она работает.

## GROUP BY и оконные функции

Например, есть таблица `sales`:

|seller|city|price|
|---|---|---|
|Alex|Moscow|100|
|Bob|Moscow|200|
|Kate|SPb|150|
|John|Moscow|300|
|Max|SPb|50|

С `GROUP BY`:
```
SELECT city, SUM(price)
FROM sales
GROUP BY city;
```

Результат:

|city|sum|
|---|---|
|Moscow|600|
|SPb|200|

С оконной функцией:
```
SELECT
    seller,
    city,
    price,
    SUM(price) OVER (PARTITION BY city) AS total
FROM sales;
```

Результат:

|seller|city|price|total|
|---|---|---|---|
|Alex|Moscow|100|600|
|Bob|Moscow|200|600|
|John|Moscow|300|600|
|Kate|SPb|150|200|
|Max|SPb|50|200|

**`GROUP BY` сокращает количество строк, а оконная функция сохраняет отдельные строки и добавляет результат вычисления.**

## OVER

`OVER()` определяет окно - набор строк, над которыми выполняется вычисление.

```
SELECT
    seller,
    price,
    SUM(price) OVER () AS total
FROM sales;
```

Пустой `OVER()` означает, что окно охватывает все строки результата, доступные оконной функции.

В данном примере каждая строка получит общую сумму всех продаж.

## PARTITION BY

`PARTITION BY` разделяет строки на группы внутри окна.

```
SELECT
    seller,
    city,
    price,
    AVG(price) OVER (PARTITION BY city) AS avg_price
FROM sales;
```

Средняя стоимость будет рассчитана отдельно для каждого города.

В отличие от `GROUP BY`, строки при этом не объединяются.

## ORDER BY внутри OVER

Позволяет задать порядок строк, используемый оконной функцией.

Например, пронумеровать продажи по стоимости:

```
SELECT
    seller,
    price,
    ROW_NUMBER() OVER (ORDER BY price DESC) AS position
FROM sales;
```

Результат:

|seller|price|position|
|---|---|---|
|John|300|1|
|Bob|200|2|
|Kate|150|3|
|Alex|100|4|
|Max|50|5|

`ORDER BY` внутри `OVER()` определяет порядок вычисления оконной функции. Для гарантированной сортировки итогового результата нужен обычный `ORDER BY` в конце запроса.

## Основные оконные функции

|Функция|Что делает|
|---|---|
|`ROW_NUMBER()`|нумерует строки|
|`RANK()`|присваивает ранг с пропусками при совпадениях|
|`DENSE_RANK()`|присваивает ранг без пропусков|
|`LAG()`|получает значение из предыдущей строки|
|`LEAD()`|получает значение из следующей строки|
|`FIRST_VALUE()`|получает первое значение в оконном фрейме|
|`LAST_VALUE()`|получает последнее значение в оконном фрейме|
Возьмём нашу таблицу `sales`:

|id|seller|price|
|---|---|---|
|1|Alex|100|
|2|Bob|200|
|3|Kate|200|
|4|John|300|

### ROW_NUMBER()

Нумерует строки по убыванию цены.

```
SELECT
    seller,
    price,
    ROW_NUMBER() OVER (ORDER BY price DESC) AS num
FROM sales;
```

Результат:

|seller|price|num|
|---|---|---|
|John|300|1|
|Bob|200|2|
|Kate|200|3|
|Alex|100|4|

### RANK()

Присваивает ранг с пропусками при одинаковых значениях.

```
SELECT
    seller,
    price,
    RANK() OVER (ORDER BY price DESC) AS rank
FROM sales;
```

Результат:

|seller|price|rank|
|---|---|---|
|John|300|1|
|Bob|200|2|
|Kate|200|2|
|Alex|100|4|

### DENSE_RANK()

То же самое, но без пропусков.

```
SELECT
    seller,
    price,
    DENSE_RANK() OVER (ORDER BY price DESC) AS rank
FROM sales;
```

Результат:

|seller|price|rank|
|---|---|---|
|John|300|1|
|Bob|200|2|
|Kate|200|2|
|Alex|100|3|

### LAG()

Получает значение из предыдущей строки.

```
SELECT
    seller,
    price,
    LAG(price) OVER (ORDER BY id) AS previous_price
FROM sales;
```

Результат:

|seller|price|previous_price|
|---|---|---|
|Alex|100|NULL|
|Bob|200|100|
|Kate|200|200|
|John|300|200|

### LEAD()

Получает значение из следующей строки.

```
SELECT
    seller,
    price,
    LEAD(price) OVER (ORDER BY id) AS next_price
FROM sales;
```

Результат:

|seller|price|next_price|
|---|---|---|
|Alex|100|200|
|Bob|200|200|
|Kate|200|300|
|John|300|NULL|

### FIRST_VALUE()

Получает первое значение в оконном фрейме.

```
SELECT
    seller,
    price,
    FIRST_VALUE(price) OVER (ORDER BY price DESC) AS first_price
FROM sales;
```

Результат:

|seller|price|first_price|
|---|---|---|
|John|300|300|
|Bob|200|300|
|Kate|200|300|
|Alex|100|300|

### LAST_VALUE()

Получает последнее значение в оконном фрейме.

```
SELECT
    seller,
    price,
    LAST_VALUE(price) OVER (
        ORDER BY price DESC
        ROWS BETWEEN UNBOUNDED PRECEDING
        AND UNBOUNDED FOLLOWING
    ) AS last_price
FROM sales;
```

Результат:

|seller|price|last_price|
|---|---|---|
|John|300|100|
|Bob|200|100|
|Kate|200|100|
|Alex|100|100|

**Важно:** для `LAST_VALUE()` мы явно указали границы окна от первой до последней строки. Без этого PostgreSQL по умолчанию использует фрейм, заканчивающийся на текущей строке (с учётом строк с одинаковым значением сортировки), и результат будет другим.

Также с `OVER()` можно использовать агрегатные функции:
```
COUNT()
SUM()
AVG()
MIN()
MAX()
```

## Пример с накопительной суммой

```
SELECT
    seller,
    price,
    SUM(price) OVER (
        ORDER BY id
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    ) AS running_total
FROM sales;
```

Результат при порядке `id` от 1 до 5:

|seller|price|running_total|
|---|---|---|
|Alex|100|100|
|Bob|200|300|
|Kate|150|450|
|John|300|750|
|Max|50|800|

`ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW` задаёт оконный фрейм: от первой строки окна до текущей включительно.

---

**Главное запомнить:**
```
OVER()              → определяет окно

PARTITION BY        → разделяет строки на группы внутри окна

ORDER BY            → задаёт порядок внутри окна

ROWS BETWEEN ...    → ограничивает фрейм внутри окна
```

Оконные функции полезны, когда нужно выполнять вычисления по группам или соседним строкам, **сохраняя детализацию исходных данных**.
