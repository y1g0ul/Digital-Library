Агрегатные функции в [[SQL]] выполняют вычисления над **набором строк** и возвращают одно значение.

Чаще всего используются вместе с [GROUP BY](GROUP BY).

Основные агрегатные функции:

|Функция|Что делает|
|---|---|
|`COUNT()`|считает количество строк|
|`SUM()`|считает сумму|
|`AVG()`|считает среднее значение|
|`MIN()`|находит минимальное значение|
|`MAX()`|находит максимальное значение|

## COUNT

Посчитать количество строк:
```sql
SELECT COUNT(*)
FROM users;
```

Посчитать количество строк, где `age` не равен `NULL`:
```sql
SELECT COUNT(age)
FROM users;
```

`COUNT(*)` считает все строки, а `COUNT(column)` - только строки, где значение столбца не `NULL`.

Можно считать только уникальные значения:
```sql
SELECT COUNT(DISTINCT country)
FROM users;
```

## SUM

Считает сумму значений столбца:
```sql
SELECT SUM(price)
FROM orders;
```

## AVG

Считает среднее значение:
```sql
SELECT AVG(age)
FROM users;
```

## MIN и MAX

Найти минимальное значение:
```sql
SELECT MIN(price)
FROM products;
```

Найти максимальное:
```sql
SELECT MAX(price)
FROM products;
```

## Вместе с GROUP BY

Например, посчитать количество пользователей в каждой стране:
```sql
SELECT country, COUNT(*)
FROM users
GROUP BY country;
```

Или среднюю зарплату по отделам:
```sql
SELECT department, AVG(salary)
FROM employees
GROUP BY department;
```

Агрегатные функции работают не с отдельной строкой, а сразу с **набором строк**.

Если используется `GROUP BY`, агрегатная функция выполняется отдельно для каждой сформированной группы.
