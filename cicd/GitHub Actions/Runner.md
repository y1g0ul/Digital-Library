Cервер, виртуальная машина или контейнер, который выполняет [[cicd/GitHub Actions/Job|jobs]]s из [[cicd/GitHub Actions/Pipeline|pipeline]]. Runner получает [[cicd/GitHub Actions/Job|job]], запускает все его [[Step]]s и сообщает результат системе CI/CD.
- Hosted Runner - предоставляется GitHub/GitLab.
- Self-hosted Runner - разворачивается пользователем на собственном сервере.
