[[процесс]]с автоматического выполнения набора задач после наступления события ([[Event]]). Pipeline состоит из одного или нескольких [[cicd/GitHub Actions/Job]]s, которые могут выполняться последовательно или параллельно.

## Для чего нужен

Автоматизирует рутинные действия:
- запуск тестов;
- сборку приложения;
- создание [[docker]]-образа;
- публикацию артефактов;
- деплой.
