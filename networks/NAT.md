**NAT (Network Address Translation)** - механизм преобразования [[networks/IP|IP]]-адресов в проходящих через маршрутизатор пакетах.

Чаще всего NAT используется для того, чтобы устройства с частными (серыми) IP-адресами могли выходить в интернет через один или несколько публичных (белых) IP-адресов.

## Как работает

Допустим, ноутбук открывает сайт:
```text
Ноутбук
192.168.1.100:54321
        ↓
Роутер
89.208.15.42:54321
        ↓
Google
142.250.x.x:443
```

Перед отправкой пакета в интернет роутер заменяет:
```text
192.168.1.100
        ↓
89.208.15.42
```

и запоминает это соответствие в таблице NAT:
```text
192.168.1.100:54321 ↔ 89.208.15.42:54321
```

Когда Google отправляет ответ на:
```text
89.208.15.42:54321
```

роутер смотрит в таблицу NAT и понимает, что пакет нужно передать:
```text
192.168.1.100:54321
```

Если внешний порт уже занят другим соединением, роутер может заменить и его:
```text
192.168.1.100:54321
        ↓
89.208.15.42:40001
```

Таким образом множество устройств внутри сети могут использовать один публичный IP.

## Типы NAT

### 1. Static NAT

Постоянное соответствие:
```text
Один внутренний IP ↔ один публичный IP
```

Например:

|Внутренний адрес|Публичный адрес|
|---|---|
|`192.168.1.2`|`89.208.15.42`|
|`192.168.1.3`|`82.103.21.43`|

Соответствие заранее настроено и не меняется.

---

### 2. Dynamic NAT

Есть пул публичных IP-адресов.

Когда внутреннему устройству нужен доступ наружу, ему временно назначается свободный публичный адрес.

Например, есть пул:
```text
89.208.15.42
82.103.21.43
```

Первое устройство получает:
```text
192.168.1.2 → 89.208.15.42
```

Второе:
```text
192.168.1.3 → 82.103.21.43
```

После завершения использования адрес может вернуться в пул.

---

### 3. PAT

**PAT (Port Address Translation)** — разновидность NAT, которая позволяет множеству внутренних устройств использовать один публичный IP благодаря [[ports]]

Например:

|Внутренний адрес|Внешний адрес|
|---|---|
|`192.168.1.100:54321`|`89.208.15.42:54321`|
|`192.168.1.101:54322`|`89.208.15.42:54322`|

Если два соединения используют одинаковый исходный порт:
```text
192.168.1.100:54321
192.168.1.101:54321
```

роутер может сделать:
```text
192.168.1.100:54321 → 89.208.15.42:54321
192.168.1.101:54321 → 89.208.15.42:40001
```

И по внешнему порту будет понимать, какому внутреннему устройству вернуть ответ.
Именно PAT обычно работает на домашних роутерах.
Его также называют:
```text
NAT Overload
```

## SNAT и DNAT

NAT можно разделить ещё и по тому, **какой адрес изменяется**.

### SNAT - Source NAT

Меняется **адрес отправителя**.

Например:
```text
192.168.1.100 → 89.208.15.42
```

Используется при выходе локальных устройств в интернет.
```text
Локальная сеть
192.168.1.100
        ↓
      SNAT
        ↓
89.208.15.42
        ↓
Интернет
```

---

### DNAT - Destination NAT

Меняется **адрес назначения**.

Например, входящий запрос:
```text
89.208.15.42:8080
```

можно перенаправить на:
```text
192.168.1.100:80
```

Схема:
```text
Интернет
        ↓
89.208.15.42:8080
        ↓
      DNAT
        ↓
192.168.1.100:80
```

Так работает **Port Forwarding** - проброс портов.

---

## Коротко

```text
SNAT
Меняем Source
→ обычно выход в интернет

DNAT
Меняем Destination
→ обычно проброс портов

PAT
Один публичный IP
→ много внутренних устройств благодаря портам
```

## Что важно запомнить
- NAT изменяет IP-адреса проходящих пакетов.
- NAT обычно используется между частной сетью и интернетом.
- **Static NAT** - постоянное соответствие `1:1`.
- **Dynamic NAT** - публичный IP временно берётся из пула.
- **PAT** - множество устройств используют один публичный IP благодаря портам.
- **SNAT** изменяет Source IP.
- **DNAT** изменяет Destination IP.
- Port Forwarding обычно реализуется с помощью DNAT.
- Домашние роутеры обычно используют PAT.
