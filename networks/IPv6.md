Internet Protocol version 6 - современная версия протокола [[IP]], созданная в первую очередь из-за нехватки IPv4-адресов.

IPv6-адрес имеет длину **128 бит**.

Записывается в шестнадцатеричном виде:
```text
2001:db8:1234:1:abcd:ef01:2345:6789
```

Адрес состоит из восьми групп по 16 бит.

## Сокращение адресов

Ведущие нули можно не писать:
```text
2001:0db8:0000:0000:0001:0000:0000:0001

↓

2001:db8:0:0:1:0:0:1
```

Одну самую длинную последовательность нулевых групп можно заменить на:
```text
::
```

Например:
```text
2001:db8:0:0:0:0:0:1

↓

2001:db8::1
```

`::` можно использовать в одном адресе только один раз.

## Структура адреса

Очень часто IPv6-сеть использует префикс `/64`.

Например:
```text
2001:db8:1234:1::/64
```

Упрощённо такой адрес можно представить:
```text
Префикс сети
2001:db8:1234:1
        +
идентификатор интерфейса
xxxx:xxxx:xxxx:xxxx
```

Но это не универсальная структура любого IPv6-адреса, а типичный вариант для `/64`.

## Виды адресов

### Global Unicast

Глобальные адреса, которые могут маршрутизироваться через интернет.

Обычно находятся в диапазоне:
```text
2000::/3
```

По смыслу похожи на публичные IPv4-адреса.

### Link-local

Используются только внутри текущего сетевого сегмента.

Диапазон:
```text
fe80::/10
```

Такие адреса автоматически появляются на IPv6-интерфейсах.

Они используются, например, для работы [NDP](https://chatgpt.com/g/g-p-6a34bab6c94c8191a0ad3487c64dc054/c/NDP).

### Unique Local

Адреса для внутренних сетей.

Диапазон:
```text
fc00::/7
```

На практике обычно используются адреса из:
```text
fd00::/8
```

По смыслу частично похожи на private IPv4.

### Loopback

```text
::1
```

Аналог:
```text
127.0.0.1
```

в IPv4.

### Unspecified

```text
::
```

Означает отсутствие конкретного IPv6-адреса.

Аналог:
```text
0.0.0.0
```

в IPv4
## Заголовок IPv6

Основные поля:
- **Source Address** - адрес отправителя.
- **Destination Address** - адрес получателя.
- **Version** - версия IP.
- **Traffic Class** - приоритет и обработка трафика.
- **Flow Label** - идентификация потока.
- **Payload Length** - размер полезной нагрузки.
- **Next Header** - какой протокол или дополнительный заголовок находится дальше.
- **Hop Limit** - сколько маршрутизаторов пакет ещё может пройти.


`Hop Limit` выполняет ту же роль, что `TTL` в IPv4.

```text
Hop Limit 3
 ↓
Hop Limit 2
 ↓
Hop Limit 1
 ↓
Hop Limit 0
```

## Дополнительные заголовки

Основной заголовок IPv6 сделали проще, чем IPv4.

Дополнительные функции вынесены в отдельные:
```text
Extension Headers
```

Например, через них реализуется фрагментация.

В IPv6 маршрутизаторы сами не фрагментируют проходящие пакеты.

## Автоконфигурация

IPv6-устройство может автоматически получить информацию о сети от роутера через:
```text
Router Advertisement
```

и сформировать себе адрес с помощью:
```text
SLAAC
```

Поэтому DHCPv6 нужен не во всех IPv6-сетях.

## Кратко

```text
IPv6
 │
 ├─ 128 бит
 ├─ запись в hex
 ├─ нет broadcast
 ├─ активно использует multicast
 ├─ Hop Limit вместо TTL
 ├─ NDP вместо ARP
 ├─ поддерживает SLAAC
 └─ огромное адресное пространство
```
