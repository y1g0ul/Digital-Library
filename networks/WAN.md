Глобальная или территориально распределённая сеть, которая соединяет между собой удалённые локальные сети и устройства.

В отличие от [[LAN]], WAN может охватывать города, страны и континенты. Самый известный пример WAN - Интернет.

## Пример
```text
Домашняя LAN
192.168.1.0/24
      ↓
   Router
      ↓
Сеть провайдера
      ↓
   Internet
      ↓
Сеть другого провайдера
      ↓
   Router
      ↓
Офисная LAN
10.0.0.0/24
```

WAN здесь соединяет две удалённые локальные сети.

## LAN и WAN

Упрощённо:

|LAN|WAN|
|---|---|
|локальная сеть|распределённая сеть|
|квартира, офис, здание|города, страны, континенты|
|обычно находится под контролем одной организации или владельца|часто состоит из сетей разных операторов|
|Ethernet / Wi-Fi|оптика, Ethernet, MPLS, мобильные сети, спутниковая связь и другие технологии|

Важно: граница между LAN и WAN определяется не конкретной технологией. Например, Ethernet может использоваться как внутри LAN, так и в сетях операторов.

## WAN-порт роутера

На домашних роутерах часто есть отдельный порт:
```text
WAN
```

К нему подключается сеть интернет-провайдера.
```text
Устройства
   ↓
LAN-порты / Wi-Fi
   ↓
Router
   ↓
WAN-порт
   ↓
Провайдер
```

Например:
```text
LAN:

192.168.1.1    Router
192.168.1.10   PC
192.168.1.20   Phone
```

А WAN-интерфейс роутера может иметь другой адрес:
```text
WAN:
203.0.113.25
```

или частный адрес провайдера, если используется `CGNAT`.

Таким образом, один роутер одновременно имеет интерфейсы в разных сетях:
```text
LAN interface → 192.168.1.1
WAN interface → адрес от провайдера
```

## Маршрутизация

В WAN основную роль играет маршрутизация. Роутеры передают IP-пакеты между различными сетями:
```text
Host
 ↓
Router
 ↓
Router
 ↓
Router
 ↓
Destination
```

Каждый маршрутизатор смотрит на destination IP и определяет, куда передать пакет дальше. Например:
```text
192.168.1.10
     ↓
домашний Router
     ↓
Router провайдера
     ↓
магистральные Router'ы
     ↓
Router другой сети
     ↓
142.250.x.x
```

## WAN и MAC

MAC-адреса не используются для адресации через весь WAN. Они работают только внутри текущего канального сегмента.

Например:
```text
ПК → Router 1 → Router 2 → Server
```

IP-пакет может идти к одному и тому же конечному адресу:
```text
Destination IP: Server
```

но на каждом участке канального уровня используются свои адреса:
```text
ПК → Router 1
MAC ПК → MAC Router 1

Router 1 → Router 2
другие L2-адреса

Router 2 → Server
ещё другие L2-адреса
```

Поэтому [[MAC]] не является глобальным адресом устройства в Интернете.

## Интернет как WAN

Интернет можно представить как огромное количество независимых сетей, соединённых между собой.

```text
Домашняя сеть
      \
Сеть провайдера
        \
      Internet
        /
Сеть Google
      /
Сеть дата-центра
```

То есть Интернет - это не одна большая LAN, а **сеть сетей**.

Для обмена маршрутами между крупными автономными сетями используется протокол [[BGP]].

## Частные WAN

WAN не обязательно означает Интернет.

Компания может соединить свои офисы собственной или арендованной сетью:
```text
Офис Москва
     ↓
   WAN
     ↓
Офис Новосибирск
```

Для этого могут использоваться:
- VPN;
- MPLS;
- выделенные линии;
- операторские Ethernet-сервисы;
- мобильные сети;
- спутниковые каналы.

## Кратко

```text
LAN
устройства внутри одной локальной сети
        ↓
      Router
        ↓
WAN
соединение удалённых сетей
        ↓
      Router
        ↓
LAN
```

`LAN` объединяет устройства локально, а `WAN` соединяет между собой удалённые сети.

Интернет - крупнейший пример WAN.
