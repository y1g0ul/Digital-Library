Border Gateway Protocol - протокол динамической маршрутизации, который используется для обмена маршрутами **между автономными системами**.

Автономная система (`AS`) - это крупная сеть или группа сетей под единым управлением, например сеть интернет-провайдера, дата-центра или большой компании.

```text
AS 100
   ↓
  BGP
   ↓
AS 200
   ↓
  BGP
   ↓
AS 300
```

## Зачем нужен BGP

В интернете огромное количество независимых сетей.

BGP позволяет им сообщать друг другу:
```text
Какие сети я знаю?
Через какие AS до них можно добраться?
Какой маршрут предпочтительнее?
```

Например:
```text
AS 100 знает сеть:
203.0.113.0/24
```

и сообщает соседям:
```text
До 203.0.113.0/24
можно добраться через AS 100
```

## AS и ASN

Каждая автономная система имеет номер:
```text
ASN
Autonomous System Number
```

Например:
```text
AS 100
AS 200
AS 65001
```

BGP использует эти номера при построении маршрутов.

## BGP-соседи

BGP-роутеры сначала устанавливают соседство друг с другом.

```text
Router A
AS 100
   ↕
  BGP
   ↕
Router B
AS 200
```

Для обмена сообщениями BGP использует:
```text
TCP port 179
```

После установки соединения роутеры начинают обмениваться маршрутами.

## AS_PATH

Один из важнейших параметров BGP:
```text
AS_PATH
```

Он показывает, через какие автономные системы нужно пройти до сети.

Например:
```text
203.0.113.0/24

AS_PATH:
300 → 200 → 100
```

Это означает, что маршрут проходит через:
```text
AS 300
 ↓
AS 200
 ↓
AS 100
```

AS_PATH также помогает предотвращать петли.

Если роутер видит свой ASN внутри полученного AS_PATH, такой маршрут он не принимает.

## Выбор маршрута

В отличие от OSPF, BGP не пытается просто найти самый короткий путь по физической сети.

Он выбирает маршрут по набору параметров и политик.

Упрощённо:
```text
Маршрут A:
AS_PATH = 3 AS

Маршрут B:
AS_PATH = 5 AS
```

При прочих равных BGP обычно предпочтёт более короткий `AS_PATH`.

Но администратор может настроить политику и выбрать другой путь.

То есть BGP отвечает не только на вопрос:
```text
Какой путь короче?
```

но и:
```text
Через кого мне выгоднее или правильнее отправлять трафик?
```

## Политики маршрутизации

Это одна из главных особенностей BGP.

Администратор может:
- предпочесть одного провайдера другому;
- запретить использование определённых маршрутов;
- влиять на входящий и исходящий трафик
- объявлять только определённые сети.

Например:
```text
Provider A → основной
Provider B → резервный
```

BGP можно настроить так, чтобы трафик обычно шёл через Provider A.

## eBGP и iBGP

Есть два основных варианта BGP.

### eBGP

`External BGP` - обмен маршрутами между разными автономными системами.

```text
AS 100 ←→ AS 200
```

### iBGP

`Internal BGP` - обмен BGP-маршрутами внутри одной автономной системы.

```text
AS 100

Router A ←→ Router B
```

iBGP нужен, чтобы распределять полученные внешние маршруты внутри своей AS.

## BGP и OSPF

Упрощённо:
```text
OSPF
↓
маршрутизация внутри сети

BGP
↓
маршрутизация между автономными системами
```

Пример:
```text
        AS 100
   ┌─────────────┐
   │    OSPF     │
   │ R1 ─ R2 ─ R3│
   └──────┬──────┘
          │
         BGP
          │
   ┌──────┴──────┐
   │    AS 200   │
   └─────────────┘
```

OSPF помогает роутерам внутри AS находить друг друга, а BGP связывает эту AS с другими сетями.

## Интернет и BGP

Интернет можно представить как большое количество автономных систем:
```text
AS 100 ─ AS 200 ─ AS 300
   \       |        /
    \    AS 400    /
     ─────────────
```

Каждая AS сообщает соседям, какие IP-сети через неё доступны.

Так постепенно формируется глобальная маршрутизация интернета.

## Кратко

```text
BGP
 │
 ├─ работает между автономными системами
 ├─ использует ASN
 ├─ использует TCP 179
 ├─ передаёт маршруты между сетями
 ├─ хранит AS_PATH
 ├─ поддерживает политики маршрутизации
 ├─ eBGP → между AS
 └─ iBGP → внутри одной AS
```

Главная идея:
```text
OSPF строит лучший маршрут внутри сети.

BGP решает,
через какие автономные системы
нужно доставить трафик в интернете.
```
