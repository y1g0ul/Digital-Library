Локальная компьютерная сеть, объединяющая устройства на относительно небольшой территории: квартира, офис, здание, серверная и т.д.

Пример домашней LAN:
```text
Ноутбук ─┐
         │
ПК ──────┼── Роутер ─── Интернет
         │
Телефон ─┘
```

Устройства внутри LAN могут напрямую обмениваться данными друг с другом.

## Адресация

Обычно внутри LAN используются частные [[networks/IP|IP]]-адреса:
```text
192.168.1.10
192.168.1.20
192.168.1.30
```

Например:
```text
Сеть:       192.168.1.0/24
Роутер:     192.168.1.1
ПК:         192.168.1.10
Ноутбук:    192.168.1.20
Телефон:    192.168.1.30
```

Все эти устройства находятся в одной IP-подсети:
```text
192.168.1.0/24
```

При этом **LAN и IP-подсеть - не строго одно и то же понятие**.

LAN описывает локальную сеть в целом, а подсеть - логическое разделение IP-адресов. Одну физическую LAN можно разделить на несколько подсетей, например с помощью [[VLAN]].

## Передача данных внутри LAN

Если два устройства находятся в одной подсети:
```text
192.168.1.10
        ↓
192.168.1.20
```
роутер для передачи данных между ними не нужен.

Компьютер определяет [[MAC]]-адрес получателя через [[ARP]]:
```text
192.168.1.20 → AA:BB:CC:DD:EE:FF
```

и отправляет Ethernet-кадр напрямую через коммутатор:
```text
ПК
 ↓
Switch
 ↓
Ноутбук
```

Для [[IPv6]] вместо ARP используется [[NDP]].

## Switch

`Switch` - одно из основных устройств LAN.

Он соединяет устройства на канальном уровне и хранит таблицу соответствий:
```text
MAC → порт
```

Например:
```text
AA:AA:AA:AA:AA:AA → port 1
BB:BB:BB:BB:BB:BB → port 2
CC:CC:CC:CC:CC:CC → port 3
```

Благодаря этому switch может отправить Ethernet-кадр именно на нужный порт.

## Router

`Router` соединяет **разные IP-сети**.

Например:
```text
LAN
192.168.1.0/24
      ↓
   Router
      ↓
Internet
```

Для устройств LAN роутер обычно является `default gateway`:
```text
192.168.1.1
```

Если компьютер хочет обратиться к адресу вне своей подсети:
```text
192.168.1.10 → 8.8.8.8
```

он отправляет пакет шлюзу.
```text
ПК → Router → Internet
```

В домашних сетях роутер обычно также выполняет:
- [[NAT]];
- [[DHCP]];
- firewall;
- маршрутизацию;
- функции Wi-Fi access point.

## Ethernet и Wi-Fi

LAN не обязательно означает проводную сеть.

Устройства могут подключаться через:
```text
Ethernet
```
или:
```text
Wi-Fi
```

Например:
```text
ПК ──Ethernet──┐
               │
               Router
               │
Телефон ─Wi-Fi─┘
```

При этом они всё равно могут находиться в одной LAN.

## Broadcast domain

Обычная LAN на Layer 2 образует `broadcast domain` - область, внутри которой распространяются широковещательные Ethernet-кадры.

Например:
```text
FF:FF:FF:FF:FF:FF
```

Такой кадр получают все устройства соответствующего broadcast domain. Роутеры обычно не передают Layer 2 broadcast из одной сети в другую.

## Пример

```text
           Internet
               │
          Public IP
               │
            Router
         192.168.1.1
          /        \
         /          \
      Switch        Wi-Fi
      /    \          \
    ПК    Сервер     Телефон
 .10      .20          .30

      192.168.1.0/24
             LAN
```

Таким образом, `LAN` - это локальная сеть, внутри которой устройства могут взаимодействовать между собой, обычно используя Ethernet/Wi-Fi, MAC-адреса и локальную IP-адресацию.
