**SNMP - Simple Network Management Protocol.**

Используется для мониторинга и управления сетевыми устройствами, серверами, UPS, [[Питание, UPS и PDU|PDU]] и другим оборудованием.

## Основные компоненты

### SNMP Manager

Система мониторинга, которая запрашивает информацию.

Например:
- Zabbix;
- PRTG;
- LibreNMS.

### SNMP Agent

Сервис на устройстве, который предоставляет информацию Manager.

Например:
```
Monitoring server
       ↓
   SNMP request
       ↓
      PDU
```

## OID

**OID - Object Identifier.**

Уникальный идентификатор конкретного параметра.

Например:
```
температура
ток
напряжение
состояние розетки
```

Каждый параметр имеет свой OID.

## MIB

**MIB - Management Information Base.**

Описание доступных параметров SNMP и их OID.

Позволяет вместо непонятных числовых идентификаторов понимать, какой параметр они обозначают.

## Polling

Система мониторинга периодически спрашивает устройство:
```
Manager → GET → Agent
Manager ← value ← Agent
```

Например:
```
Какой сейчас ток?
→ 6.2 A
```

## SNMP Trap

Устройство само отправляет сообщение о событии.

```
PDU
 ↓
SNMP Trap
 ↓
Monitoring
```

Например:
```
Overcurrent
High temperature
Outlet failure
```

Главное отличие:
```
Polling → Manager спрашивает устройство
Trap    → устройство само сообщает о событии
```

## Версии

### SNMPv1 / SNMPv2c

Используют community string.

Защита слабая.

### SNMPv3

Поддерживает:
- аутентификацию;
- шифрование;
- более безопасный доступ.

## Команды Linux

Получить конкретный параметр:
```
snmpget
```

Посмотреть дерево доступных параметров:
```
snmpwalk
```
