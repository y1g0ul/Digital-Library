## 7. What is SNMP?

SNMP is a protocol used for monitoring and managing network devices.

A monitoring system can request information from an SNMP agent.

For example, it can read current, voltage, temperature or device status.

A device can also send SNMP traps when an event happens.

## 8. What is a PDU?

A PDU is a Power Distribution Unit.

It distributes electrical power to equipment in a server rack.

A smart PDU can also monitor power usage and remotely control individual outlets.

## 9. What is a Smart PDU?

A Smart PDU is a network-controlled power distribution unit.

It can monitor voltage, current and power consumption.

It can also remotely switch outlets on or off and integrate with monitoring systems.

## 10. What is a watchdog?

A watchdog checks whether a device is still working.

For example, it can check ping or a TCP port.

If the device stops responding, the system can automatically restart it by switching its power off and on.

## 11. What is IPMI?

IPMI is used for remote server management.

It works through the BMC controller.

With IPMI, you can check hardware status, power state, sensors and logs.

You can also use remote KVM to access the server console even if the operating system is not working.

## 12. What is PXE?

PXE is a way to boot a computer over the network.

The computer gets network settings from DHCP and then downloads boot files from a server.

It is often used for operating system installation, recovery and server deployment.
