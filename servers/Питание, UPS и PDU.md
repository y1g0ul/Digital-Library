## Основные величины

### Сила тока

Количество электрического заряда, проходящего через проводник за единицу времени.

Обозначение:
```
I
```

Единица измерения:
```
Ампер — A
```

### Напряжение

Разность электрических потенциалов между двумя точками.

Обозначение:
```
U
```

Единица измерения:
```
Вольт — V
```

### Мощность

Скорость потребления или передачи энергии.

Обозначение:
```
P
```

Единица измерения:
```
Ватт — W
```

Для упрощённого расчёта:
```
P = U × I
```

Например:
```
230 V × 2 A = 460 W
```

## Однофазная и трёхфазная сеть

Однофазное питание обычно используется непосредственно для серверного оборудования.

Трёхфазное питание используется для передачи больших мощностей и распределения питания внутри дата-центра.

## UPS (ИПБ)

**UPS - Uninterruptible Power Supply.**

Источник бесперебойного питания.

Используется для:
- питания оборудования при пропадании внешней сети;
- защиты от проблем электропитания;
- обеспечения времени до запуска резервного источника.

### Основные типы UPS

**Offline**

В нормальном режиме нагрузка питается от сети.

При пропадании сети UPS переключается на батарею.

**Line-interactive**

Может корректировать часть проблем напряжения без перехода на батарею.

**Online**

Нагрузка постоянно питается через преобразователь UPS.

Обеспечивает максимальную изоляцию нагрузки от внешней сети.

## PDU

**PDU - Power Distribution Unit.**

Устройство распределения питания внутри серверной стойки.

Упрощённо:
```
UPS / электросеть
       ↓
      PDU
       ↓
 ┌─────┼─────┐
Server Switch Storage
```

## Типы PDU

### Basic PDU

Просто распределяет питание.

### Metered / Monitored PDU

Дополнительно измеряет параметры:
- ток;
- напряжение;
- мощность;
- энергопотребление.

### Switched PDU

Позволяет удалённо включать и выключать розетки.

### Smart PDU

Совмещает:
- мониторинг;
- удалённое управление;
- защиту;
- сетевой интерфейс;
- интеграцию с системами мониторинга.

## Разъёмы

Часто используются:

### IEC C13

Обычно используется для серверов и сетевого оборудования с небольшой и средней нагрузкой.

### IEC C19

Используется для оборудования с большей мощностью.

Также может использоваться обычный европейский разъём **Schuko**.

## Схема питания сервера

Сервер с двумя блоками питания может подключаться к двум независимым линиям.

```
UPS A → PDU A → PSU 1
                  \
                   Server
		
UPS B → PDU B → PSU 2
```

Если один источник питания выходит из строя, сервер продолжает работать от второго.

Такая схема называется резервированием питания A/B.
