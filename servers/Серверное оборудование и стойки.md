Серверное оборудование - компьютеры, предназначенные для длительной работы под нагрузкой, удалённого управления и установки в дата-центрах.

## Серверные стойки

Серверное оборудование часто устанавливается в стандартные 19-дюймовые стойки.

Высота оборудования измеряется в **юнитах - U**. (4,445 см)

```
1U
2U
3U
4U
```

Чем больше U, тем больше места занимает сервер в стойке и тем больше компонентов в него можно установить.

Для установки серверов используются:
- рельсы;
- салазки;
- направляющие.

## Отличия сервера от обычного ПК

Серверы обычно имеют:
- несколько сетевых интерфейсов;
- отдельный интерфейс управления [[OOB|BMC/IPMI]];
- резервируемые блоки питания;
- ECC-память;
- [[RAID]]/HBA-контроллеры;
- hot-swap диски;
- большое количество накопителей;
- систему удалённого управления;
- конструкцию, рассчитанную на постоянный воздушный поток.

## Серверные процессоры

Серверные процессоры рассчитаны на:
- длительную работу под высокой нагрузкой;
- большое количество ядер и потоков;
- работу с большим объёмом оперативной памяти;
- поддержку ECC;
- работу в многопроцессорных системах;
- расширенные возможности виртуализации.

Примеры:
- Intel Xeon;
- AMD EPYC.

В одном сервере может быть установлено несколько процессоров.

При этом память и PCIe-устройства могут быть физически привязаны к конкретному CPU.

Это связано с архитектурой **NUMA** - Non-Uniform Memory Access.

Упрощённо:
```
CPU 1 ── RAM 1
  │
  └── PCIe devices

CPU 2 ── RAM 2
  │
  └── PCIe devices
```

Процессор быстрее работает со своей локальной памятью, чем с памятью другого CPU.

## Серверная оперативная память

В серверах обычно используется память с поддержкой **ECC - Error-Correcting Code**.

ECC позволяет обнаруживать и исправлять часть ошибок оперативной памяти. Это важно для систем, которые должны долго работать без сбоев.

### UDIMM

**Unbuffered DIMM**

Обычная небуферизованная память.
- меньшая задержка;
- небольшой максимальный объём;
- чаще используется в рабочих станциях и младших серверах.

### RDIMM

**Registered DIMM**

Между контроллером памяти и микросхемами находится дополнительный регистр.

Преимущества:
- позволяет устанавливать больше памяти;
- снижает нагрузку на контроллер памяти;
- широко используется в серверах.

### LRDIMM

**Load-Reduced DIMM**

Дополнительно уменьшает электрическую нагрузку на контроллер памяти.

Используется там, где требуется очень большой объём RAM.

### Каналы памяти

Процессор имеет несколько каналов памяти.

Например:

```
CPU
├── Channel A → DIMM
├── Channel B → DIMM
├── Channel C → DIMM
└── Channel D → DIMM
```

Для максимальной производительности память желательно устанавливать симметрично и с учётом рекомендаций производителя сервера.

## Форм-факторы

Обычные ПК:
- ATX;
- Micro-ATX;
- Mini-ITX.

Серверные платы могут использовать:

- E-ATX;
- EE-ATX;
- проприетарные форм-факторы.

## Охлаждение

В дата-центрах используется разделение на:
- **холодный коридор** - воздух поступает к передней части серверов;
- **горячий коридор** - нагретый воздух выходит с задней стороны.

Воздух обычно проходит через сервер:
```
Холодный воздух
      ↓
[ FRONT SERVER REAR ]
      ↓
Горячий воздух
```

Компоненты внутри сервера располагаются так, чтобы как можно меньше мешать воздушному потоку.

## Типы серверных систем

### Rack server

Обычный стоечный сервер.

Устанавливается непосредственно в стойку и занимает определённое количество U.

```
[ 1U Server ]
[ 1U Server ]
[ 2U Server ]
```

Плюсы:
- стандартный формат;
- удобно обслуживать;
- каждый сервер относительно независим.

### Blade server

Несколько серверных модулей - **blade** - устанавливаются в общий chassis.

```
Blade chassis
├── Blade 1
├── Blade 2
├── Blade 3
├── Blade 4
└── ...
```

Общий корпус может предоставлять:
- питание;
- охлаждение;
- сеть;
- управление.

Позволяет очень плотно размещать большое количество серверов.

### Twin server

В одном серверном корпусе находятся несколько независимых серверных узлов.

Например:
```
2U chassis
├── Node 1
├── Node 2
├── Node 3
└── Node 4
```

Каждый узел может иметь свои:
- CPU;
- RAM;
- сеть;
- накопители.

При этом часть инфраструктуры, например питание и охлаждение, может быть общей.

### Multi-node server

Общее название для систем, где в одном chassis размещено несколько независимых вычислительных узлов.

Twin-сервер является одним из вариантов multi-node архитектуры.

Такие системы используются для высокой плотности вычислений.

### Cloud server platform

Серверные платформы, рассчитанные на размещение большого количества однотипных вычислительных узлов.

Обычно оптимизированы для:
- высокой плотности;
- виртуализации;
- горизонтального масштабирования;
- массового обслуживания серверов.

Главная идея:
```
Rack server
→ один корпус = один сервер

Blade / Multi-node
→ один общий корпус = несколько серверных узлов
```

## Резервирование компонентов

Серверное оборудование часто проектируется так, чтобы отказ одного компонента не останавливал систему.

Например:
```
PSU 1 + PSU 2
```

Это называется резервированием.

Схема `1+1` означает:
- одного блока достаточно для работы;
- второй является резервным.

Также может использоваться схема `N+1`, когда к необходимому количеству компонентов добавляется один резервный.

## Hot-swap

**Hot-swap** - возможность заменить компонент без выключения сервера.

Часто hot-swap поддерживают:
- HDD/SSD;
- блоки питания;
- вентиляторы.

Но поддержка зависит от конкретной серверной платформы.

## U-colocation

**U-colocation** - размещение оборудования клиента в стойке дата-центра.

Дата-центр предоставляет:
- место в стойке;
- питание;
- сеть;
- охлаждение;
- иногда удалённое обслуживание оборудования.

Оборудование остаётся собственностью клиента.
