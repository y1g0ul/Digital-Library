**ATS - Automatic Transfer Switch.**

Автоматический переключатель между двумя источниками питания.

Используется для повышения отказоустойчивости.

Упрощённая схема:
```
Источник A ──┐
             ├── ATS ─── оборудование
Источник B ──┘
```

В обычном режиме нагрузка получает питание от основного источника.

Если основной источник пропадает или его параметры становятся недопустимыми:
```
Source A ❌
    ↓
   ATS
    ↓
Source B ✅
```

ATS автоматически переключает питание на резервный источник.

## A/B питание

В дата-центрах часто используются две независимые линии питания:
```
UPS A → PDU A
UPS B → PDU B
```

Сервер с двумя блоками питания подключается так:
```
PDU A → PSU 1
PDU B → PSU 2
```

Если одна линия [[Питание, UPS и PDU|питания]] выходит из строя, сервер продолжает работать от второй.

Это позволяет избежать единой точки отказа.
