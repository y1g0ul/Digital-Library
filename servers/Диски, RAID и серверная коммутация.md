## Накопители

Основные типы накопителей:

### HDD

Механические накопители на магнитных дисках.

Плюсы:
- большой объём;
- низкая стоимость за гигабайт.

Минусы:
- высокая задержка;
- низкая скорость случайных операций.

### SSD

Накопители на основе flash-памяти.

Быстрее HDD, особенно при случайном доступе.

### NVMe

SSD, работающие через PCI Express.

Отличаются:
- высокой пропускной способностью;
- низкой задержкой;
- большим количеством операций ввода-вывода.

Форм-факторы NVMe:
- M.2;
- U.2/U.3;
- PCIe Add-In Card.

## Интерфейсы дисков

### SATA

Распространённый интерфейс для HDD и SSD.

Часто используется в обычных ПК и недорогих серверах.

### SAS

Серверный интерфейс.

Преимущества:
- высокая надёжность;
- dual-port;
- поддержка серверных дисковых систем.

### NVMe

Использует PCIe напрямую и обычно значительно быстрее SATA/SAS SSD.

## HBA

**HBA - Host Bus Adapter.**

Контроллер, который предоставляет операционной системе прямой доступ к дискам.

Часто используется вместе с программным RAID или файловыми системами вроде ZFS.

## RAID-контроллер

Аппаратный контроллер, объединяющий несколько дисков в RAID.

Может иметь собственный:
- процессор;
- RAM-кэш;
- защиту кэша.

Некоторые RAID-контроллеры временно записывают данные в быстрый кэш и позже сбрасывают их на диски.

Для защиты кэша при потере питания могут использоваться:
- батарея;
- supercapacitor;
- flash-память.

## Cache Protection. 

Контроллер и батарейка. Данные отправляемые на диск записываются в контроллер и он отдает ответ, что они записаны и он уже дописывает их на диске. Есть у него флешка. Даже если потерялось электропитание модуль запишет данные на флешку/
## Backplane

**Backplane** - плата внутри сервера, к которой подключаются диски.

```
Disk
Disk
Disk
Disk
 │
 ▼
Backplane
 │
 ▼
HBA / RAID controller
```

Позволяет удобно подключать большое количество накопителей и использовать hot-swap.

## Сетевые интерфейсы сервера

Сервер может иметь несколько сетевых портов.

Например:
```
NIC 1 → основная сеть
NIC 2 → резерв / другая сеть
BMC   → сеть управления
```

Количество интерфейсов зависит от конкретного сервера.

Отдельный BMC-порт используется для [[OOB|Out-of-Band Management]].

## Консольный порт

Консольный порт используется для локальной настройки сетевого оборудования, особенно когда устройство ещё не имеет сетевой конфигурации.

Через него можно получить CLI устройства напрямую.

## Management port

**Management port** - сетевой интерфейс, предназначенный для управления устройством.

Обычно через него работают:
- Web UI;
- [[networks/SSH|SSH]];
- SNMP;
- API.
