**СКС - структурированная кабельная система**.

Это система кабелей, разъёмов, патч-панелей и других элементов, которые соединяют сетевое оборудование, серверы и рабочие места.

## Витая пара

Медный кабель для передачи данных по [[Ethernet]].

Обычно используется с разъёмом **RJ-45**.

Примеры категорий:
- Cat5e;
- Cat6;
- Cat6a.

## Патч-корд

Готовый короткий кабель с разъёмами на концах.

Используется для соединения:
```
Server → Switch
Switch → Patch panel
Patch panel → другое оборудование
```

## Патч-панель

Панель, в которую заведены кабельные линии. Используется для удобной организации и перекоммутации соединений.

## Оптоволокно

Передаёт данные с помощью света.

Преимущества:
- высокая пропускная способность;
- большие расстояния;
- устойчивость к электромагнитным помехам.

## Single-mode и Multi-mode

### Single-mode

Используется для больших расстояний. Имеет небольшой диаметр сердцевины и передаёт один основной световой режим.

### Multi-mode

Используется на меньших расстояниях, например внутри дата-центра. По волокну распространяется несколько световых режимов.

## Оптический кросс

Аналог патч-панели для оптоволокна.

Используется для:
- окончания оптических линий;
- организации соединений;
- удобной перекроссировки.

Упрощённо:
```
Switch
  ↓
SFP / SFP+
  ↓
Оптический патч-корд
  ↓
Оптический кросс
  ↓
Магистральное волокно
```

## SFP

**SFP - Small Form-factor Pluggable.**

Съёмный модуль, который устанавливается в сетевое оборудование.

Позволяет подключать:
- оптоволокно;
- иногда медный Ethernet.

Основные варианты:
- SFP - обычно до 1 Гбит/с;
- SFP+ - обычно до 10 Гбит/с;
- QSFP - используется для более высоких скоростей.

## Tx и Rx

В оптическом соединении используются направления:
- Tx - передача;
- Rx - приём.

Для связи:

```
Tx одного устройства → Rx другого
Rx одного устройства ← Tx другого
```

Если линии перепутаны, соединение не поднимется.
